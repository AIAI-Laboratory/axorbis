# Desktop app

Tauri loads the React UI from `web/` and starts `integration/review_runner.py` through `src-tauri/src/commands.rs`. The runner uses SynthScholar 0.0.11 search and full text clients for a Computer Science literature map. See the [root README](../README.md) for installation, supported sources, evidence rules and output files.

From the repository root, run `npm run desktop:dev`. The start form accepts a topic, optional core concepts and related terms, and a result limit. The run view shows search, screening, abstract enrichment, full-text resolution, evidence and quality gate progress. Abstract passages count as limited evidence for high-level claims; full-text passages are strong evidence for detailed claims and gap verification. Result views show source level, basic and deep evidence coverage, the corpus, exact passages, matrix, claims, scoped gap counter-searches, query provenance and diagnostics. Abstract-only gaps remain unverified. A run with insufficient evidence remains inspectable without being called complete. Legacy review folders are still readable through their existing views.

Keys are never stored in the review folder or browser storage. Provider keys and selected Gemini keys are passed to Python through stdin. Gemini is optional and can profile search concepts; without a key, the deterministic concept and evidence pipeline still runs. OpenAlex can use a key when configured. Rerunning creates a new output folder and repeats acquisition.
